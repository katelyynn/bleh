hello everyone!! this is a very big step for bleh, probably the largest update in a long time. more work will happen after this one, but this needed to be put out first :3

as usual, report bugs in the normal process

# Rewrite
- __Re-written a large amount of bleh in TSX__
	- This means better code quality, probably better performance, better components (that you can feel and see already), and more stability. It fixes that recent bug regarding *x values instead of y* and other randomness.
	- Contributed initially by @ohmaigotto
- Moved bleh to now be built with Deno
	- Contributed by @ohmaigotto
- Implemented a new tooltip/menu system
	- Contributed by @ohmaigotto

# Profile
- __Introduced profile streaks!__
	- If you listen to an artist (from there, an album and/or track) on repeat it will show up above yours (or others) recent tracks. Streaks cap out at 100 to avoid large API requests, but by that point you can take a browse for yourself.
	- The initial timestamp (well, capped to 100) of the streak start is displayed alongside each value when clicking.
	- Streaks less than 15 will display less prominently than those above or equal to 15.
	- I may implement caching at some point to avoid a large amount of API requests in the future, but we will see how it goes for now.
- __Introduced a new design for Events__
	- This refreshed design can be seen on your profile’s *Events* tab and on artist pages. It brings a greater focus onto the event and if you are attending/interested - along with a proper design for once.
	- This will extend to the mini previews on page sidebars soonish.
- __Fixed leaving a shout not clearing your textbox__
	- This involved re-building the entire markdown field that is used for that area, but it was worth it in the end.
- __Re-designed the inbox view in the top right to use new tabs__
	- These can also be seen on your profile when editing your panels
- Improved the look of activities
	- The underlying system is still flawed, but that will be looked at in due time.
- Fixed some *Bulk Edit* incompatibility as much as I can
	- Some workarounds had to be implemented to fix the fragile-ness of how *Bulk Edit* injects itself and its various features.
- You can now access settings for recent tracks on other profiles
- The badge dialog now has coloured highlights on hover
- Adjusted the colours of graphs to match *Plot*
	- Will probably have a second pass at some point for better colouring.
- Changing settings such as ‘show guest features’ now updates in realtime
- Disabling the *Your progress* feature now works again
- Fixed clicking a *Pro* badge sometimes linking to the buy page

# Settings
- __Re-built all setting components from scratch__
	- They now support state management and are reactive to changes around them, for example, you can change your theme in the top-right menu and watch it update realtime in settings. This also means settings can react to incompatibilities the moment they happen.
	- This also allowed me to do a big pass on some older settings (with more to come in future updates) to make bleh easier to customise.
- __Introduced 3 new themes__
	- Say hello to *Rosé Pine*, *Rosé Pine Dawn*, and *Kanagawa (Dragon)*. These are the first of many hopefully in the future, just need to clean up the theme system internally a bit first.
- __Introduced a new colour selector__
	- Presets are now separated into their own category, with the usual sliders and conversion setting being below it. If you aren’t sure what colour to pick and want to choose around without your previous disappearing, that is now possible! Just make sure you have finalised before leaving the page as it will then disappear.
- __Introduced a new display name selector__
	- It now uses a carousel by default, with clicking the middle revealing a grid view of all possible options.
- __Changed the avatar shape slider into 3 options__
	- This doesn’t remove any options (the slider was already split into 3), it just allows me to define the radius separate from the actual visual number. This also means more presets can be added in the future.
- __Lists (such as *Music linking* or *Close friends*) now allow dragging items to move__
	- This replaces the janky left and right arrows that appeared on hover to let you re-arrange items.
- __Re-designed the seasonal timeline__
	- Turning on/off seasons now disables per-season settings too.
- __Added a preview for profile bleh settings__
	- Configure markdown and ‘your progress’ visibility easier.
- Introduced new fun, clickable, keybind settings
- Stylised the username change screen a bit
- Added links to other settings around to help navigation
- Introduced new menu checkbox items
