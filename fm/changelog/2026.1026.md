# Seasonal

# Collage
- __Updated dependency for additional features__
- __Modernised the header for collages__
- __Add blurs and subtle shadows to collage detail text__
- __Introduced a new *Stack* mode__
	- This changes your collage from a grid to a bookshelf-like row of items. Subsequent items render behind the last.
- __Changing collage visual settings now refreshes faster__
	- Instead of requesting information again, the collage now uses the data already collected to regenerate the collage with your new visual settings.
- Your collage background is now based on your bleh colour
- Fixed the display of smart titles in collages
- Collage now shows detailed steps of what is in progress

# Profile
- Optimised backgrounds and banners on profiles further
- __Shrunk the size of page headers a bit__
	- ..and also increased the legibility of the text by moving the banner a bit to the side, while preserving the aspect ratio.
- __Added a ‘show pie chart’ option for the profile summary graph__
	- This now sums up your chart into every month mentioned, similar to previous functionality.
- __Adjusted the legibility of profile sub text__
	- There’s a subtle layer of blur behind the text, smaller icons, denser information, and the ‘follows you!’ indicator is now highlighted first.
- Fixed profile heatmap linking to incorrect months
- Fixed profile banner backgrounds being smaller due to regressions
- Fixed profiles having incorrect border radiuses due to regressions
- Increased the blur resolution of profile backgrounds from `400` to `1300`
	- You will be able to make out more identifiable details in the background of pages, which makes it a bit more interesting to view.
- Adjusted the look of listening reports and radios on the sidebar to take up less space
- Introduced some basic fixes to the set obsession page
- Adjusted the icon for starred friends to be simpler

# Library
- __Updated the *glacier* design__
	- The majority of the library design has been re-written to use newer components and have live updating settings. You can see this when browsing through yours or someone else’s library.
	- Settings are now in a more familiar location and contains small setting items when clicked open.
	- Counters will now start from 0 and tick upwards to show the scale.
	- There will probably be more changes here in the future but this is a good first step towards modernising I feel.
- Fixed artist scrobble bars not responding to theme changes
