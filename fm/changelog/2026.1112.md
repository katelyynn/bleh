heyo everyone!!! this is a really chilly update with some awesome changes buuuuut:

i wanna use this space js to talk on the bleh outlook going forward. there’s some huge chunks of bleh that still haven’t been migrated to TSX, which leads to some of the UI looking a little out of date or even broken compared to the rest. this will be sorted out!! it’ll just take time to fully finish that up. for next year, i want to focus on integrating more tools into bleh, specifically in terms of scrobbling, non-pro editing, discogs linking?, and more like that.

thank u everyone for sticking around <3
# Seasonal
- __Upgraded the seasonal effects for *Winter* seasons__
	- Much better card overlays, with additional seasonal tops to round them off near the top of cards.
	- Snow no longer has a per-frame computed glow, its now a static image with its own glow baked in. Much better performance with no real visual cost.
- Adjusted the timings of seasons

# Design
- __Introduced a very small refresh to page layout__
	- The main and side cards are now split into their own columns, with the tabs above now floating a bit too. Seasonal decorations are now rendered on each card instead of the tab row too.
- Link underlines can now once again go multi-line while still being animated
- Improved the look of lighter themes
- Fixed some track names clipping without ellipsis
- Adjusted the colours used for *Plot* graphs
- Redesigned the footer

# General
- __Optimised how themes are declared__
	- This should in turn lead to much better performance overall, as individual buttons no longer have to scan the entire document for theme changes.
- __Reduced animations to improve perceived optimisation__
	- Hovering over tracks and a few other areas is now instant, which from testing is perceived as being more performant than before.
- Optimised the track love button to take less tree searching
- Added some content visiblity off-screen performance stuff to shout and markdown rendering
- Optimised how quickly bleh can cold-start from page loading
- The stylesheet is now appended ever so slightly faster
- Fixed the page loader bar animation breaking
- Removed the page theme transitions for performance

# oracle
- __Fixed choosing ‘Own plays’ not loading til you clicked it again__
- oracle is pending its move to TSX, so some components will probably look out of place in the meantime. Please standby.

# Navigation
- __Redesigned the top page navigation__
	- The navigation now takes up the full width of the page, allowing the middle content to move upwards and be less crowded in its area of the screen.
	- The search bar now has a bigger presence, with a dialog with results(?) intended to appear soon-ish.
	- The upper right seasonal indicator now flips between the season and the standard bleh settings button.
- __Introduced a new combined inbox button__
	- This button has the same functionality as before, but no longer combines the notification dots of your notifications and messages.
	- Right-clicking this button now allows you to access the dedicated page faster.
- Fixed the broken animations on page tabs

# Profiles
- __Adding a group of socials and status.cafe to your profile is now in the Markdown field__
	- This means you can find 2 new buttons when editing your bio, one for adding links to your socials in a dedicated container, one for showing your status.cafe status.
	- These existed in bleh for a while, but were never exposed to the user interface until now.
- __Fixed attempting to edit from libraries causing errors__
- __Redesigned the top track/obsession card__
	- This now uses a clone of the tracklist to show the track, which fixes any text clipping etc. issues.
- Fixed obsession & loved track headers
- Fixed the tags page a bit
- Fixed the outline radius of your avatar if you set it to anything other than rounded
- Fixed the profile … menu not closing when clicking some options

# Settings
- If you have no profile banner entered, you can no longer click the empty preview
- Profile settings now have placeholder text again
- __Re-built the *Account* Last.fm settings tab__
	- This now uses the newer TSX components and is much nicer to use.

# Collage
- __Clicking *Collage* on someone’s profile now uses their username again__
	- This regressed at some point this year, but it is now fully functional again.
- Having no close friends in bleh now displays a small message informing you of such.
	- Noticeable when creating a *Collage* as the dropdown uses this close friends list to populate it.

# Modals
- ModalV2 now supports reference elements
	- This opens the door to a reworked edit track/album modal!

# Menus
- Right-click menus can no longer appear off screen
- Adjusted the minimum width of menus

# i18n
- __Updated Deutsch translation by @zozoloft__

# Other
- __Re-factored lotus and the bleh updater to use ISO dates__
- If you haven’t checked for updates for over a month, you should now be prompted
- Updated branding for *Record Club*
- Introduced a new `TextFlip` component among others
- Fixed select menus with no value showing `undefined`
