hello this update is very long overdue but i have also been very hard at work on it for mostly the entire time. the last update was quite rushed due to recent last.fm changes, so this one has had more time for polish.

# Performance
- __Improved performance drastically across the project__
	- You should notice quicker load times, less style refreshes, less stutters, etc.
	- There will probably be some places that have regressed in styling due to this, but they will be fixed up in a more optimised way another time.
- __Implemented lazy-loading for shout parsing and album grid colouring__
	- These heavy workloads will now only trigger once you scroll them into view, saving on performance all at once.
- __If navigating between pages fails you will now properly see an error__
	- This would previously just cause an infinite loop and slow down your browser, now you can actually tell what went wrong instantly
- __Increased performance of background blurring__
	- Basically all realtime blurs have been replaced with a static, one-time background blur which is shown as page backgrounds. There’s a little bit of delay in loading it but it pays off for performance gains.
	- There should also be less flashing when navigating between pages too, as banners aren’t replaced if they’re identical now.

# Design
- __Moved from a hsl-based system to oklch__
	- Compared to hsl, oklch is designed to much more closely match how humans perceive colours and their vibrancy. It is a very different system to hsl and as a result, **your custom colour will probably look different than before**.
	- This change will only happen once, so now is a nice time to try out the new colour sliders!
	- The colour conversion system has also been improved as an up-side, try inputting a hex code and see the result!!
- __Added new font options__
	- You can now choose from a selection of pre-bundled fonts, namely the new *Stylistic* default, the previous *Simple* default, *Accessible* or your own custom font
- __Reduced the size of buttons and other interactables__
	- Aiming to not bloat the interface so more genuine music information is readable
- __Redesigned the user menu__
	- Now has a better look for your badge and all your controls in a smaller form
- Moved ‘now playing’ from user menu to it’s own navigation item
- __Added a cute disc image for album and track page headers__
	- Animates nicely on hover, along with the cover art itself. Can be toggled off in the ‘visual’ tab if you choose.
	- There’s also a nice animation on hover for this avatar, like there used to be
- Redesigned the colour scheme of lotus to reflect the flower counterpart
	- Also restored the flower motif by showing the icon in more places again
- Changed the design of sidebar call-to-actions such as lotus and oracle
- Fixed the awkward gap above sidebar buttons
- Added a nice animation for tooltips appearing and disappearing
	- Bit inconsistent on first creation of a tooltip but I don’t wanna spend any more time on it atm
- Increased the contrast of the *Void* theme for easier distinction
- Improved the look of the *Ink* theme as it has recently regressed
	- More work will be done in the future

# Profile
- __Added a profile summary to the top of pages__
	- This summarises your recent 30 day listening into a heatmap per-day. Brighter days have more listens, darker days have fewer - all based relatively on your own listens.
	- To the side of it, you can find the relocated 90 day line graph and an additional pie chart to accompany it.
	- Above it are the relocated scrobbles, artists, and loved track statistics now in a much easier place to compare between profiles.
- __Fixed profile caching not refreshing properly__
- Fixed hitting backspace on an empty profile setting causing spam
	- This was commonly causing banners to become empty or profile names to not work properly, this is all fixed.
- __Fully standardised profile banner sizing__
	- Banners now have a strict aspect ratio that maintains until you reach lower screen resolutions, at which you probably would expect the ratio to change

# Music
- __Redesigned the top summary panel for pages__
	- Taking inspiration from the profile redesign, this splits the top of albums, artists, and tracks into 2 columns. The first column contains the wiki, length/lyrics, social links, tags, and copyright.
	- The second column is now the home of your scrobbles along with a 30 day heatmap of global listeners on the page. Below it you can see the amount of listeners in this 30 day period.
	- The aim of this is to make music feel more connected and less isolating - seeing others listening along with you to songs you like should help with that.
- __Automatic colour picking is now enabled for artists and tracks__
	- Along with this, the cover art is now the source of colour and matches between album grids and album pages. You can turn this off per-page, by heading to the *Visual* tab in settings like usual.
- __Added album easter eggs__
	- Take a look at the titles for [Slayyyter](https://www.last.fm/music/Slayyyter)’s *[WOR$T GIRL IN AMERICA](https://www.last.fm/music/Slayyyter/WOR$T+GIRL+IN+AMERICA)* or the font on [Charli xcx](https://www.last.fm/music/Charli+xcx)’s *[brat](https://www.last.fm/music/Charli+xcx/brat)* to understand. More will appear in the future, they just have to be simple and not too intrusive. Open to suggestions!!
- __Redesigned ‘colourful count bars’__
	- There’s now a new gradient of colours that are picked from for each scrobble count, along with better handling of the darker colours (50k+) with the text changing to fit contrast.
- Introduced an option to reverse bleh’s flipping of count bars
	- aka. you can now have your scrobble count bars start from the left instead of right again if you so choose
- Fixed crashes related to importing lotus data
- Fixed some music links not disappearing if disabled

# oracle
This release has many, many improvements to oracle as i’m sure you will notice. I am confident that oracle will be the new default in bleh once its quirks are ironed out. Continue testing please :3

- __Improved the recording search to specify strictly recordings__
	- This ensures it doesn’t pick up albums which share the same name, and only picks real songs.
- __Fixed names which contained any ‘special characters’ (quotations, dollar signs, other languages, whatever) not finding proper results__
	- I was accidentally encoding these twice which caused the search to basically ignore them or give weird results like searching for “recording” as a name
- __A temporary cache is now stored between subpages__
	- Loading an album will now store it’s data if you head to the wiki or the shoutbox then head back in the same tab without a full page reload
	- Caching of albums and tracks has also now changed to store simply the id which can be used for a much quicker MusicBrainz lookup
- __Introduced initial support for fetching artists via oracle__
	- This will be used to gather a plethora of extra information to display on artist pages, currently being used to show country, birth date, death date, and artists in a group/band.
	- Try hovering over the birth or death date of an artist and see if it has the corresponding location too, not sure if the flags will fully work in this case yet.
- __Introduced track credits__
	- You can now view who contributed to a song’s composition, down to the instruments and vocals if the information is present on MusicBrainz.
- __Artists which use aliases will now correct to their Last.fm name__
	- For example, *BULLY* is released under Ye on MusicBrainz, but it now links to the Kanye West page on Last.fm for parity with streaming services. I will likely be implementing an alias system for artists in the future, both to choose between official aliases and also let you choose your own capitalisation possibly.
- __Releases listed as an *EP*, *Single* will now appear on ‘album’ pages__
	- Take a look at the little text above this release title once it loads from oracle, [girl EDM](https://www.last.fm/music/Ninajirachi/girl+EDM)
- Fixed ‘explicit’ being used as the artist name in a track right-click menu
- Adjusted colours of brands to be more pastel and cute
