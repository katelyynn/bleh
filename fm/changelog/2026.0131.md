hello everyone!! this is the update originally scheduled for December… and now January… it contains so so so so so so so so many changes that i probably missed a bunch so i guess u will have to explore for urself :>

# Profiles
- __Re-designed how banners are displayed__
	- Banners now have a mostly standardised sizing ratio, with the main focus of the image being displayed at the top now (rather than being spread out on the sides of the page)
	- A blurred out version of the banner is now used for the page background to compensate
- __Pronouns are now automatically detected and separated from your user title__
	- Along with this, the row showing account creation date, your ‘aka.’, and username has been redesigned to be more compact
- __Improved taste compatibility features__
	- The text representation of your compatibility is now displayed when you click onto your taste percentage itself. It’s also now more obvious you can click this if you didn’t know before.
	- There’s a new ‘Copy’ button in this menu which allows you to copy a more Last.fm-style format for sharing with other users.
- __Fixed random breakage of Last.fm Playback__
	- Wasn’t really my fault but now bleh completely unloads if it detects its presence
- Replaced listening report quilts with bleh’s collage feature
- Fixed rendering of report cards
- Changed colouring and shadows of various themes in different ways
- __Added a (early, in-progress) ‘Manage’ button to profiles__
	- Currently allows copying the username and sharing links but in the future will house easier access to blocking and reporting users. It could also be useful for any less relevant features that don’t need to take up sidebar space.
- Artist and album grid sizes are now calculated on the fly
	- This should reduce cases where the width/height does not match expectations
- Your plays compared to last month now accompany your scrobble graph

# Markdown
- __Introduced an inline markdown editor__
	- Now replaces the textboxes when writing shouts or editing your bio, a markdown editor with syntax highlighting built from the ground up. It’s probably still rough around the edges in a few areas, notably bold/italics and losing focus after inserting links and images.
	- I’ve also noticed the textbox should probably clear again after a shout is successfully sent, but it’s a little hard to track that at the moment (will probably come at some point).
- __Introduced support for ‘status.cafe’ in your bio__
	- Use the profile setting interface or add `[status=username]` into your bio to display your current status to everyone viewing, it’s position based on where it’s placed in the textbox.
- __Introduced support for Discord-style timestamps__
- Fixed spacing inconsistencies when adding images
- Fixed the inconsistency of how strikethrough text is displayed
	- It’s now used to show smaller text
- Fixed `<hr>` separators not showing in some markdown places

# Friends
- __Re-introduced bleh friends system as ‘Close friends’__
	- This is separate to the following lists on Last.fm and controls (in the future) which users you will see recent listening history from, see their statistics on music pages, and setting a starred friend.
	- You can view and change your close friends at any time by adding ‘Friends’ to your navigation menu and hitting the little arrow button accompanying it.
	- Wondering how to edit your top-right navigation menu? A right-click can do wonders
- __Re-added hidden close friends button on profiles__
- __A new highlight shows if users are following you__
	- Moved from showing as a badge to below your username
- __Added new default ‘Cards’ friends list view__
- Cleaned up snippets of user bios that contain bleh-style markdown
- Fixed removing an unrelated close friend resetting your starred friend
