hello everyone!! this is the latest bleh update, a bit spookier than the last release. the spirit of halloween has taken over all aspects of the interface, with some buttons looking more crooked and damaged than usual - and a lot of cobwebs to suite.

head to the *Seasonal* tab in settings to toggle these to your liking. speaking of:

# Seasonal
- __Upgraded seasonal effects__
	- *Halloween* and *Fall* now feature new decorations and colour presets.
- __Added new mask effects for seasons__
	- The *Halloween* season now has a hand-drawn rough look to interactables and grids.
- __Re-written the seasonal system__
	- Seasons can now change on the fly with all components updating to match the current season instantly. Try turning it on and off in the settings and watch things change.
- Seasons can now control a new overlay type
- Fixed snow not rendering correctly in colder seasons

# Minis
- __Added a new user selector for *Collage* and *Compare*__
- __Redesigned the layout of said minis to now have settings on the right and content on the left__
	- Collages now also feature a neat grid preview on the right based on the real width and height.

# Design
- __Introduced new music listen items__
	- These reflect how many plays you or other people have on a song/album/etc.
	- You can now see *all your friends* on music pages. Hover over their card to view their listens.
- __Added a new design for link underlines__
- Fixed overflow in floating panels
- Fixed themes in listening reports
- Experimented with more themes that may be released in the future
- Adjusted the sizing of some elements like side actions
- Added icons to more themes
- Reduced the perceived sizing of tags on music pages
- Added cute animations to a bunch of icon interactions

# Shouts
- __Added a new hover & menu design for shout avatars__
- Added separators between shouts for easier legibility
- Shouts that aren’t hovered now decrease in opacity

# Profiles
- __Changed profile graphs to show your last 60 days on a line graph__
	- As apposed to the previous graphs, the new line chart now has data for *each individual day*. This gives a much better insight into someone’s listening patterns at a glance.
- __Added a report option to profiles__
	- Takes you straight to the Last.fm forums, as that is the only actual place where people can get banned.
- __Redesigned profile taste compatibility__
	- A redesign was planned for a while as the current one was a placeholder, this one may get some extra additions but it’s a better start I think.
- Fixed *About Me* sidebars causing crashes
	- Contributed by [hsyslm](https://github.com/katelyynn/bleh/commits?author=hsyslm)
- Fixed badge lookup causing crashes when logged out
	- Contributed by [hsyslm](https://github.com/katelyynn/bleh/commits?author=hsyslm)
- Fixed profile settings resetting your avatar cache
- Increased the legibility of profile descriptions

# Layout
- __Re-built a lot of music pages to use tsx__
- __Introduced a new music links system__
	- The links you edit and the order of them in settings now take immediate effect on music pages.
	- Some links now have new strings and icons too.
- Added a new ‘Search’ music link
	- Allows you to search for the artist/album/track name via the native Last.fm search
- Modernised tag pages partially
- Modernised some page headers

# Settings
- __Re-arranged some settings__
- __Select menus now accept typing__
	- You can use the arrow keys to navigate and type text to search through available options.
- Redesigned the feature flags system
- Fixed switches not updating on theme immediately

# Markdown
- Fixed inserting images not updating markdown previews
- Fixed pinterest images not loading correctly
- External links are now marked with an icon
- Added the markdown disabled alert to settings
- Further sanitised markdown to fix textboxes

# Sponsors
- Added new fonts for sponsors

# Other
- Fixed flag candidates causing crashes in some instances
- Upgraded deno and project dependencies
- Fixed updater symbol not displaying initially
- Settings are now loaded alongside pages again
- Fixed captchas not loading properly in some cases
- Fixed timeframe dialogs closing prematurely
- Fixed empty dialogs causing crashes
	- Contributed by [hsyslm](https://github.com/katelyynn/bleh/commits?author=hsyslm)
- Moved theme declarations into their own files
