hello everyone!! this update is focused on bringing more colour and expressiveness to the whole of bleh, with lots of interfaces being more influenced by your accent than previous :3
# Home
- __Redesigned the home tab from scratch__
	- You can now see your top 50 albums in the last month in a sweet carousel inspired by older Apple designs.
	- Interested in what your friends are listening to? Add them as a *close friend* in bleh, and their active listening will display on the right.
	- Additionally, the usual sections below have been re-ordered in a way I think more closely matches what people would be interested in.
	- Please give feedback as this is very new and experimental.

# Minis
- __Added a new mini *Plot*, to map out listening history__
	- Compare your listens between multiple albums, tracks, artists, or even people on your close friends list. Any data can be added with a set timeframe shared between them.
	- This is a new, work-in-progress feature, so please do give a feedback.
- __Fixed the rendering of *Collage* under certain scenarios__
	- Grid item details should now look nicer, the new (much cleaner) bleh logo is now used, items won’t be weirdly rounded or shaded anymore etc.

# Design
- __Redesigned the top bar to focus on your music__
	- Added quick links to the global charts and bleh Minis, along with hiding the bleh version info to the bottom of the page.
	- The search bar now has an icon that can be middle-clicked to open the global search page, in case you wanted it in a new tab.
- __Swapped the colour algorithm for 1000x performance increase__
	- (and more accurate colours)
- __Added more hints of colour throughout__
	- Areas like sidebars, sidebar buttons, and tab icons are now tinted based on the page’s current accent.
- __Fixed up all theme declarations__
	- This means that *Ink* visibility is no longer degraded, along with the colour changes previously mentioned. The page backgrounds in light theme are no longer only grey.
- __Added fancy outlines when hovering various album and artist grids__
- __Added a new (optional!) *Serif* font for headings__
	- Adds some nice personality flair in my opinion, can be turned off with all the other font options if it’s not your thing
- __Replaced top-left branding logos with svgs__
	- This allows for much more consistent rendering and nicer masking especially with theme switching and seasonal changes
- Adjusted design of *new* badges to make them more noticeable
- Adjusted the design of tabs, toolbars, buttons, etc.

# Profile
- __Redesigned the tastemeter to fit better in the new layout__
- Re-ordered profile about to be below side action buttons
	- There is now also a nice separator to show this is user-created content and everything below is different
- Fixed *status.cafe* embeds not rendering some apostrophes and fancy symbols properly
- Fixed graph blocks moving to a new line too early
- __Fixed cloning a scrobble at the current time not working__
	- No clue how long this was broken, never got reported though
	- This also might hopefully fix the dialog not replacing properly if you turn off ‘auto close’
- __Fixed obsession pages__
	- For some reason this wasn’t reported either
- Fixed the display of first-to-claim obsession items
- Fixed the context menus of obsession items

# Settings
- __Added new menu versions of some settings__
	- Can be seen when right-clicking the bleh logo
- __Your avatar is now updated within bleh if you change it__
	- You no longer need to refresh the tab to get some areas to update
- Fixed calendar timeframe controls closing when selecting a year sometimes

# Music
- Added new smart tag variations
- Changed wording of *Country* to *Origin* to better reflect some scenarios
