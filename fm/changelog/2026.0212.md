# Music
- __Re-implemented shoutbox previews on artist, album, and track pages__
	- Following the Last.fm removal of these previews, I have re-implemented them essentially 1:1 using the same endpoint they were previous. Last.fm might (probably will) remove this endpoint soon/eventually if they’re going forward with this so I have an extra feature flag to make it load the entire shoutbox in the future.
	- No more “start the conversation” buttons
- __Fixed pages being marked as ‘limited’__
	- Due to the changes Last.fm made above, the check for limited pages (nsbm mainly) has been reworked, you probably won’t ever see it again
- Fixed live tags not accounting for dashes
- Changed wording of ‘listens’ to ‘plays’ to match grids

# Scrobbling
- __You can now swap track→album and artist→album artist fields when creating a scrobble__
	- This helps in case you accidentally write into the wrong field without looking and lets you easily move the names into the correct position. You can find the button to the side of the 2 text fields with pointy arrows.
- __Added a ‘auto close’ option for said modal__
	- Allows you to easily continue adding more scrobbles after the last one. There will be a ‘lock’ feature in the future to keep some input fields the same between scrobbles, along with more work on upping the time field by a base 3 minutes or so etc.
 - The ‘save edit’ button is no longer being overridden which might hopefully fix bulk edit
	 - Again haven’t had the time to test this update fully yet
