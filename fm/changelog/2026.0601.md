# Gallery
- __Refreshed the design of the gallery__
	- The original gallery redesign was made in 2024 and bleh evolved around it overtime, so this update brings it more to the standards of today.
	- The vote total (positive - negative) is now present below the upvote/downvote buttons, both as a ratio bar and a number.
- Starring or saving artwork will now fill the icon
	- Helps better show the state at a glance (filled icon = active)

# Minis
- __Collages now support custom timeframes__
	- Following the timeframe picker made for *Plot*, it is now also useable when creating collages. Ever wanted to make a collage of that one specific week? Now you can.
- Fixed custom timeframes closing early if typing in a manual date
	- Press *Enter* to submit a manual date now

# Music
- Fixed *King Crimson* being detected as blocked
	- While image uploads are blocked, he has a special restricted level of `2` from Last.fm, so this is now accounted for differently.
- Fixed various crashes when viewing restricted pages
- Fixed random crash related to a tracklist being `null`
- Fixed alignment of close friends list on the *Mutual listeners* sidebar
- [Adjusted alignment of *Charts* ranking](https://github.com/katelyynn/bleh/pull/434)

# Profile
- Fixed crash when viewing anyone’s `/now` page
- Improved legibility of profile badges in all themes
- Improved legibility of profile headers in light theme
- Fixed profiles who only had one shared artist
- Fixed manually entering a close friend closing early

# Design
- Increased legibility of some controls
- Adjusted legibility of tabs a lot
	- Removed the text shadow and replaced it with a subtle gradient behind the tabs themselves, makes the text look a lot less hollow
